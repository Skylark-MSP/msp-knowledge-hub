# Skylark MSP Knowledge Hub V5

This version adds a signature paper-plane entrance animation. The plane launches from the header Skylark logo area, follows a smooth arc through the viewport, briefly zooms at the center, then returns and docks back into the logo. The existing authentication, dynamic KB browsing, and read-only PDF viewer are preserved.

Upload `index.html` to the root of `msp-knowledge-hub` and keep the `assets/` folder containing the existing isometric animation files.
